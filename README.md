## 👨‍💻 About Me

Hi, I'm **Sumair** — a software engineer who builds full stack web applications and cross-platform mobile apps.

I work across the stack: responsive **React** front ends, **Node.js / Express** REST APIs, **MongoDB / MySQL** databases, and **Flutter** apps for Android and iOS. I care about clean code, solid database design and software that is easy to maintain.

- 🌐 Full Stack Development with the **MERN** stack
- 📱 Cross-platform mobile apps with **Flutter & Dart**
- 🔌 REST API design and third-party API integration
- 🧠 Object-oriented design, debugging and problem solving
